# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
versioning follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [2.0.1] - 2026-11-17

### Changed

- **Releases are automated**: pushing to `master` verifies the version files,
  creates the annotated `vX.Y.Z` tag when missing and publishes the GitHub
  Release with the matching changelog section.

### Fixed

- **Editing while the interface is rotated**: focusing a field temporarily
  restores the natural viewport orientation so the on-screen keyboard matches
  the app, then returns to the chosen rotation. The saved rotation is not
  changed.

## [2.0.0] - 2026-11-16

### Added

- **Quest shortcut in the phase header**: in the quest phase, a second
  “Calculate progress” button next to the phase title opens the same quest
  resolution dialog, so it stays within reach while scrolling. The existing
  button under step 3.4 remains.

### Changed

- **Rewritten as a React + Vite + TypeScript app**, keeping the same UI, rules,
  animations and keyboard/screen-reader labels. Tailwind 4 and shadcn-style
  primitives now live in `src/`; the old `app.js`, `styles.css` and `i18n.js`
  were removed.
- **Build and deploy** now produce a static bundle in `dist/` with
  Cloudflare Pages (`npm run build`), instead of shipping the raw files.
- **PWA** is generated by `vite-plugin-pwa`: the service worker precaches the
  built bundle, `version.js`, the manifest and icons, and still works offline.
  The version remains a single source of truth in `version.js`.
- **Tests** were added: Vitest covers storage migrations, sanitisation, game
  transitions and IT/EN dictionaries; Playwright covers phone, tablet, rotated
  dialogs and offline startup.

### Fixed

- Notes edited inside a combat process now close back to that process, as
  before, and the process stays open.
- Undo clears an active quest-threat flash so the counters do not show a stale
  “+X”.

### Compatibility

- **The `localStorage` contract is unchanged**: `rings-turn-log/v1`, the legacy
  `lotr-lcg-memo/v1` key and 1.0.0 `minaccia` saves keep loading, including
  turn, phase, players, threat, bookmark, quest, notes, settings, rotation and
  language.

## [1.3.2] - 2026-11-15

### Added

- **Action window between 6.6 and 6.7** in the combat phase, matching the rules
  sequence. Like the other gaps it can host notes and the bookmark.
- **Long-press on the quest resolution `−`/`+` buttons**: one step on press,
  then fast repetition after 380 ms (same timing as Turn and Threat). The
  limits (Willpower −999…999, Threat 0…999) and the lock after applying the
  threat increase still apply.

### Changed

- **Rotation icon**: it is now a screen that shows the orientation the button
  switches to — landscape in portrait, portrait when the UI is rotated — so it
  no longer looks like “New game”. The old `reload.svg` is no longer used and
  was removed.

### Fixed

- **Pop-ups no longer spill outside their panel in landscape or with the UI
  rotated** (for example the **Close** button of the quest progress, which ended
  up below the rounded border or off-screen). Panels keep their content height
  and compact on short screens, so the whole dialog stays inside the border; the
  overlay scrolls only when the content truly does not fit.

## [1.3.1] - 2026-11-15

### Added

- **Game-over sound**: `game-over.mp3` plays when a player's threat reaches 50.
  It fires once per crossing (going below and back above plays it again) and
  also when the increase comes from Refresh or from the quest resolution; Undo
  and reopening the app with the threat already high stay silent. The file is
  in the service worker precache.

### Changed

- **Player name editable on phones too**: tap the “Threat · Name” label to open
  the rename dialog, as on tablets. Previously names could only be changed in
  tablet mode.

### Fixed

- Long player names no longer squeeze the neighbouring Turn counter on phones:
  the label truncates with an ellipsis and both cards keep the same width.

## [1.3.0] - 2026-11-15

### Added

- **Quest resolution (step 3.4)**: a pill under the step opens a pop-up with
  **Willpower** and **Threat**, both with `−`/`+` buttons and direct entry.
  Willpower can go below zero, Threat cannot. The result is
  `Willpower − Threat`: when it is zero or positive the **progress counter**
  appears with its own icon; when it is negative a **“Raise threat by X”**
  button appears, raising every player's threat by X with a visual effect on the
  counters.
- **`willpower.png`, `threat.png` and `progress.png` icons**, used in the pop-up
  and added to the service worker precache.

### Changed

- **New name: Rings Turn Log**. Updated brand, page title (just the name, no
  “Turno” suffix), PWA manifest (name, short name, description), iOS title,
  service worker cache (`rings-turn-log-v…`) and `localStorage` key
  (`rings-turn-log/v1`); saves under the previous key are read and migrated
  automatically. The brand name compacts below 380 px to leave room for the
  controls.
- After applying the threat increase the pop-up **closes itself**, so the effect
  is visible on the counters right away; fields and buttons stay locked and
  **Undo** restores threats, entered values and the unlocked state.
- When the result is zero or positive, the **Close** button appears below the
  progress.
- The quest resolution resets when moving to the next turn and with
  “New game”.

## [1.2.0] - 2026-11-15

### Added

- **Single-step bookmark**: tap the step (or the ribbon next to it) to mark it;
  the bookmark is unique and moves when you tap another step. The marked row
  gets a gold bar and the stepper shows a yellow dot on the matching phase
  (including combat process steps, which mark phase 6).
- **Bilingual IT/EN interface**: the top-right button toggles the two languages
  and the choice is remembered. Besides UI texts, phase and process names, rules
  steps, history labels, pop-up titles and accessible messages are translated
  too. English step texts follow the rules terminology. The initial language
  follows `?lang=`, then the saved preference, then the browser language, with
  Italian as fallback.
- **Phase names in the tablet stepper**: with enough room, each button 1–7
  shows the number and the phase name.

### Changed

- The **notes dot** in the stepper is now **purple**; the bookmark uses a second
  **yellow** dot at the bottom right, so the two stay distinguishable even on
  the gold current phase.
- “New game” also clears the bookmark (still recoverable with Undo).
- The **fullscreen** button was removed from the header and replaced by the
  language selector; code and markup are ready to re-enable it.
- Phase names in the stepper update with the language, without rebuilding the
  buttons.
- **Updated sounds**: `tap.mp3`, `undo.mp3` and `new-round.mp3` were replaced
  with new recordings.
- **Radix icons**: bookmark, notes, rotation, undo, new game, close and add use
  the [Radix Icons](https://www.radix-ui.com/icons) set (MIT). Only the files
  used are in the root; the full `icons/` folder is excluded from git.

## [1.1.1] - 2026-11-14

### Added

- **Undo sound**: pressing Undo plays `undo.mp3` (instead of the generic tap).
  The file is included in the service worker precache.

### Changed

- **More visible threat reminder**: gold ring on the card, “!” badge and a hint
  in a gold pill, with a stronger pulse.
- **NEXT** and jumping to another phase implicitly confirm the current starting
  threat (30): the reminder turns off without changing the value.

### Fixed

- The reminder starts again with “New game” too, when the threat was left at the
  default 30 (before, the animation did not restart).
- **Fullscreen + rotation**: the rotated UI sizes are computed in pixels and
  realigned to the screen, avoiding the “widescreen” effect with squashed
  phases on Android.
- The service worker completes installation even if an optional asset (for
  example a sound) is unavailable.

## [1.1.0] - 2026-11-14

### Added

- **Tablet mode**: from 600 px of short side, up to **4 threat counters**
  appear, one per player, with custom names.
- **Adding and removing players** (minimum 1, maximum 4) with an “Add player”
  tile; these actions are undoable too.
- **Player name** editable by tapping the card label; an empty name falls back
  to “Player N”.
- **Per-player threat reminder**: independent pulse and hint on each card.

### Changed

- The saved state now stores `players` (name, threat, per-player reminder)
  instead of a single `minaccia`.
- **Refresh**: +1 threat for every player.
- **New game**: keeps names and roster and resets each player's threat to 30.
- On phones a single threat card remains (player 1), with the name next to it
  when set.

### Fixed

- The threat and name dialogs show which player they refer to and remain
  reachable with the keyboard open.

### Migration

- 1.0.0 saves are converted automatically into a single player with the
  previous threat and reminder.

## [1.0.0] - 2026-11-14

First public release.

### Added

- **Turn and Threat counters**: `−` / `+` buttons with long-press to scroll
  fast, and tapping the number to set any value (default 30). Threat turns red
  from 50 upwards.
- **7-phase tracker** with the numbered rules steps (1.1, 1.2, …) and action
  windows highlighted.
- **Combat processes in pop-ups**: “Resolve Enemy Attacks” and “Player Attacks”,
  opened from steps 6.4a and 6.8a.
- **Notes between steps**: add, edit and delete, several notes in the same gap,
  inline purple display, a dot in the stepper and preservation after
  “New game”.
- **NEXT** phase by phase; from Refresh it starts the next turn (Turn +1,
  Threat +1, back to Resource).
- **Undo** up to 30 steps, including undoing “New game”.
- **UI rotation** between portrait and landscape, with the choice remembered
  across sessions.
- **Fullscreen** where supported by the browser.
- **Screen wake lock on/off** with saved preference and reacquisition when
  returning to the app.
- **Sound effects** for taps and for the start of a new turn.
- **Starting threat reminder**: on first launch and after “New game” the
  counter pulses briefly and a hint remains until the value is set; saves from
  previous versions are not affected.
- **Installable, offline-first PWA**: manifest, service worker with app shell,
  icons and audio precache, automatic updates and offline operation after the
  first load.
- **Visible versioning**: version shown next to the brand, with `version.js` as
  the single source of truth and the service worker cache tied to the version.
- **Top-aligned pop-ups and keyboard handling**: overlay height follows the
  visible area via `visualViewport`, including with the UI rotated 90°.

### Changed

- **Action windows** have a more discreet style: faint red band, text aligned
  left at the same indent as the steps.
- The phase card content is top-aligned.
